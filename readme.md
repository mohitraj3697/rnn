# RNN Lab

A collection of hands-on experiments and implementations with **Recurrent Neural Networks (RNNs)** and sequence-based deep learning.

The goal of this repository is to understand RNNs through practical implementations, experiments, and small projects.

## What's Inside

* Vanilla RNN experiments
* LSTM implementations
* GRU experiments
* Bidirectional RNNs
* Sequence prediction
* Text and NLP experiments
* Model training experiments
* Loss and accuracy analysis
* Experiments with different hyperparameters and architectures

## Tech Stack

* Python
* Keras
* TensorFlow
* NumPy
* Pandas
* Matplotlib
* Jupyter Notebook
